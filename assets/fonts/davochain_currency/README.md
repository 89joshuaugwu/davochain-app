# Davochain Currency

Custom Davochain Naira mark, selected by the product owner on 16 October 2026. Authored vector outlines; private-use glyph U+E900. One Davochain Naira represents NGN 1.

Use DavoNairaAmount for financial display and DavoCurrencyMark for the standalone identity. Do not use the private-use character in raw clipboard text, provider messages or OS notifications. Plain text uses the amount and Davochain Naira; banking contracts use NGN. The font is not a new public Unicode/ISO currency assignment.

Vector source and amount-size proof: docs/design/davochain-naira. Numeral typography remains Sora; the currency glyph is the only custom-font span.
